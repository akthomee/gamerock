What is an OBB File?

You downloaded an APK, but the game won't start. Now you're being told you need an OBB file. Here is exactly what it is, why it exists, and how to install it correctly so your game actually works.

5 Min Read

If you are new to downloading APKs from third-party sites, you have probably run into this roadblock: You download a 20 MB file for a massive 3D game. You install it, you open it, and you get a black screen, a "Download Failed" error, or a message saying the game is missing its data files.

Welcome to the world of the OBB file.

If you don't know what an OBB is, installing these games can feel impossible. But once you understand what it does and where it goes, the whole process takes about 30 seconds. Here is everything you need to know.

What is an OBB File?

OBB stands for Opaque Binary Blob. In simple terms, it is a massive data file that contains all the heavy assets for a game—textures, audio, 3D models, and level files.

When you download a game from the Google Play Store, Google handles this automatically. But when you download an APK manually, the APK itself usually only contains the code. The OBB contains the actual game itself.

Why Do Games Use OBB Files?

Years ago, Google placed a strict limit on the size of an APK. If a game was bigger than 50 MB, developers couldn't host it on the Play Store.

To get around this, developers split their games in two. They made a tiny APK (the installer) and a massive OBB file (the data). Google updated the Play Store long ago to allow larger apps, but many classic games (especially Gameloft titles like N.O.V.A. and Asphalt) were built around the OBB system, so they still rely on it today.

Where Does the OBB File Go?

This is where 99% of people mess up. If you just put the OBB file anywhere on your phone, the game will not find it.

The OBB file must be placed in a very specific folder on your Android's internal storage.

The path is exactly:
/Android/obb/package_name/

Let's break that down:

  • /Android/obb/ — This is the folder where Android expects all game data to live.
  • package_name/ — This is the unique identifier of the game (e.g., com.gameloft.android.ANMP.GloftN2HP). You cannot make up a folder name. It must match the package name of the APK you installed.
  • main.obb — The OBB file itself must often be renamed to "main.obb" to be recognized by the game.

How to Install an OBB File (Step-by-Step)

Here is the exact process to get the game running.

  1. Download the APK and the OBB: We host both files on our download pages. The OBB is usually delivered inside a ZIP or RAR archive.
  2. Extract the Archive: Use a file manager (like MT Manager) or an app like ZArchiver to extract the OBB file from the ZIP.
  3. Find the exact folder: Open your file manager and navigate to Android/obb/. Look for a folder with the game's package name. If it doesn't exist, create it.
  4. Move the OBB: Move your extracted OBB file inside that folder.
  5. Install the APK: Now, install the APK. The game will launch, find the OBB, and load your assets.

Modern Android and Virtual Machines

If you are on Android 11, 12, 13, or 14, there is a new problem. Google restricted access to the Android/obb/ folder for privacy reasons. Your standard file manager might not be able to move files into it anymore.

This is exactly why we recommend using VPhoneOS or F1 VM. Inside a virtual machine, you have full root access. You can use MT Manager to drag and drop the OBB into the right folder without fighting Android's security restrictions.
