What each tool is about

Every tool in this category solves a different problem. Here's a quick breakdown of what each one does.

  1. VPhoneOS — a virtual machine that gives you a rooted Android 12 environment on any phone without rooting your device. Runs 32-bit games on modern 64-bit phones, supports Magisk without unlocking your bootloader, and lets you run multiple VMs at once. The most capable virtual machine available.
  2. F1 VM — a lighter virtual machine running Android 7 with built-in root access. Simpler than VPhoneOS and works on older devices, but has an older Android version and weaker 32-bit support. A solid alternative when VPhoneOS isn't an option.
  3. GameGuardian — the actual memory editor. Search for and change values in a running game (coins, health, ammo, XP) using fuzzy searches, encrypted value searches, Lua scripts, speedhack, or freezes. Works directly on rooted devices, or inside a virtual machine on unrooted ones.
  4. MT Manager — a powerful file manager and APK editor. Reaches files Android normally hides, and can edit dex, xml, arsc, and hex without needing root. Handles ZIP editing, APK signing, cloning, optimization, translation, and script execution.
  5. IL2CppDumper — a reverse-engineering tool for Unity games. Reads the compiled IL2Cpp binaries of a game and produces a readable dump of class names, method names, and field offsets — the map you need before you can change anything.

Pick whichever tool matches what you're trying to do. VPhoneOS and F1 VM give you a rooted environment. GameGuardian is for editing values. MT Manager is for files and APKs. IL2CppDumper is for reading compiled game code.
