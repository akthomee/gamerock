How the tools work together

These four tools aren't competitors — they're a kit. Here's how a typical modding workflow uses them:

  1. F1 VM — install this first if your phone isn't rooted. It gives you a rooted Android environment to run the other tools in.
  2. GameGuardian — the actual value editor. Use it to search, modify and freeze game memory. Always launch it before the game.
  3. MT Manager — the file workhorse. Extract, edit, repack APKs, move OBB folders, patch dex or XML files.
  4. IL2CppDumper — the analyst. Dump a Unity game's compiled code to find the values you want to change.

Not every game needs all four. Start with GameGuardian — if you can find the value directly, you're done. Reach for the others when you need to dig deeper.
