What IL2CppDumper is about

IL2Cpp stands for Intermediate Language to C++. It's a Unity-developed scripting backend. Unity supports two main scripting backends: .NET and IL2Cpp.

IL2CppDumper is used in reverse-engineering files so as to hack them. In game hacking/modding it's essential for working with the banning system, among other things. IL2CppDumper also makes it easy to search for and find values inside a Unity game's compiled code.
