// About

What GameGuardian is about

GameGuardian is a memory editor developed by a group of programmers and hackers — the package name alone (catch_.me_.if_.you_.can_) tells you that. A memory editor allows you to view and modify the contents of memory. Here, the memory being edited is the data in RAM for the software you want to modify.

In simple terms, GameGuardian is the best tool for hacking games on Android. Its many functions allow you to perform different searches to edit almost everything. You can even record processes and execute downloaded scripts. So far it's the most flexible — and the best — tool for cheating in Android games.

For unrooted devices, GameGuardian usually needs a virtual environment like F1 VM, Parallel Space, or VMOS to operate. F1 VM is the most recommended. On the other hand, rooted devices need no virtual environment for GameGuardian to work.

// Features

What's inside GameGuardian

  • Runs on ARM, x64 and x86 devices, including x86 emulators (LDPlayer, Droid4X, MOMO, KOPlayer, Andy, Memu, Leapdroid, AMIDuOS, Windroye, RemixOS, PhoenixOS, AVD, Genymotion, Nox, BlueStacks etc.).
  • Supports Android 2.3.3+ (Gingerbread) through Lollipop (5+), Marshmallow (6+), Nougat (7+), Oreo (8+), Pie (9+), 10+.
  • Works without root via different virtual spaces.
  • Supports different emulators like PPSSPP, ePSXe, GameBoy etc.
  • Game deceleration and acceleration (speedhack) for ARM and x86 devices, including x86 emulators. Also supports both 32-bit and 64-bit applications on 64-bit devices using speedhack.
  • Search feature: encrypted values.
  • Search of unknown values when specifying the difference between values.
  • Search addresses by mask.
  • Explicit and "fuzzy" numeric searches.
  • Text (String, Hex, AoB) search.
  • Supports Double, Float, Qword, Dword, XOR, Word, Byte, or Auto data-type searches.
  • Lua scripting support.
  • Modify all search results at once.
  • Filtering of search results (address greater than and less than, value greater than and less than).
  • Search in the background feature.
  • The fill feature.
  • Copy memory.
  • Time jump feature.
  • Dump memory.
  • Customizable UI.
  • App locale for over 50 languages.
  • And much, much more.
