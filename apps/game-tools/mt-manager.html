// About

What MT Manager is about

MT Manager is a very powerful file manager and editor. By default, on Android 9–12, we can't access certain files. With MT Manager the case is different — we can access files that our Android makes difficult to reach, and modify or translate them easily.

If you want to modify your device's system directory, you'll need root access — but that isn't mostly needed. Besides, there's a lot of fun to catch without root access.

// Features

What's inside MT Manager

  • Effective file handling system — copy, move, delete. If you give root privilege to MT, you can access the system directory, remount the file system as read-write, and modify file permissions and owner.
  • Open ZIP files like WinRAR. You can rename, move, delete, add, or replace external files in the ZIP without decompression and repackaging — and decompress files in the ZIP.
  • Many powerful APK editing features — arsc editor, dex editor, xml editor, hex editor. You can also sign APK, clone APK, optimize APK, remove signature verification, anti-confuse APK resources, translate apps.
  • APK Encryption.
  • Text editor with syntax highlighting.
  • Creating backups (.bak).
  • Fonts viewing.
  • Script execution.
